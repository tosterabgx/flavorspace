# flavorspace

Cooking challenges for you and your friends

> This version is still only MVP. Currently, there's only one challenge added, without any pictures whatsoever.
> Though, you can check the design and try "making" dishes

The idea came to me pretty spontaneously. I once though, what if there was a MySpace (facebook), but for recipes? I decided to make cooking a bit more interesting, so you could discover more recipes. Later, I will probably add more challenges, more recipes and some cool features like cooking alongside friends!

## Testing it

## Features

- Accounts, signup + login with email and password
- Home page with dishes cooked this week and overall, progress bar on the challenge
- Challenges, which you can browse and see their dishes (there's only one yet)
- Recipes with some meta info, ingredients and steps

## Tech stack

- Next.js
- Tailwind CSS
- Drizzle ORM
- Supabase
